# 盘古 50K 标准版：40P 接口 GPIO 虚焊检测方案

> 适用板卡：盘古 50K **标准版（MES50HP）**  
> FPGA：紫光同创 **PGL50H-6IFBG484**  
> 开发工具：Pango Design Suite（PDS）/ Verilog HDL  
> 检测接口：40Pin 扩展接口 **J8**  
> 检测范围：**仅 34 路 GPIO（J8 物理脚 3～36）**；不对电源脚、地脚进行功能测试  
> 文档定位：工程实施方案与 RTL 结构参考，**不是已经编译验证的完整 PDS 工程**

## 1. 检测目标与关键结论

在不拆除 40P 插座的前提下，尽可能通过 FPGA 程序筛查：

- GPIO 从 FPGA 到 J8 接触端的断路、明显虚焊；
- 轻微触碰、温度变化或连接器受力时出现的间歇性接触不良；
- 待测两脚之间疑似短路、驱动异常或输入异常（需进一步交叉验证）。

**重要限制：** 仅在 FPGA 内部将信号输出再读回、或仅检查 FPGA 引脚配置，不能证明 40P 插座焊点导通。必须让信号**经过插座对外连接触点**再返回 FPGA，才能对插座端的连接路径进行有效测试。

**本方案选择：相邻两脚成对、双方向环回。** J8 上 3～36 脚共有 34 路 GPIO，分为 **17 对**（3↔4、5↔6……35↔36）。每对分别做 **A→B** 和 **B→A** 测试；一次只驱动一只 GPIO，另一只配置为输入。这样每个 GPIO 都至少经历输出和输入两种工作模式。

即使一对测试失败，也只能首先确定**该对连接路径存在异常**；无法仅凭一次失败断言“其中哪一个焊点虚焊”。单脚定位需要使用已确认正常的参考脚进行交叉复测（见第 7 节）。

## 2. 板卡及接口核对

来自小眼睛科技《盘古 50 开发板（MES50HP）硬件使用手册》，第 35 页（PDF 零基页索引 35，手册印刷页 35/38）的表 3-12：

- J8 为 2×20、2.54 mm 40Pin 扩展接口；
- **3～36**：34 路 GPIO；
- **1、37、38**：GND；
- **2**：5V0；
- **39、40**：A3V3；
- 主芯片：PGL50H-6IFBG484。

板载调试资源（同一版硬件手册）：

| 功能 | FPGA 封装脚 | 用途 |
|---|---|---|
| `FPGA_GCLK_50M` | `P20` | 检测状态机、串口时钟来源 |
| `UART0_TX` | `R9` | 通过板载 CP2102 和 Type-C 发送检测结果至 Windows |
| `UART0_RX` | `R8` | 可选：从上位机接收选中测试对/开始命令 |

> **版本核对：** 本表专门按 **MES50HP 标准版**写成。不要将盘古 50KN 网口版、50KH 视频版，或盘古 50Pro 的其他管脚文件直接照搬。虽然部分版本 J8 管脚表相似，也应以你手上的标准版实物丝印、官方原理图和硬件手册为最终依据。

## 3. 硬件工具与接线方法

### 3.1 推荐的最简材料

1. Windows 电脑、PDS、板卡正常的 JTAG 下载连接；
2. 一根与 J8 插座类型匹配的杜邦线或 2×20 排针转接板/排线；
3. 一只 **1 kΩ 串联限流电阻**（每次跨接两脚时串入信号路径）；
4. 推荐增加 **10 kΩ 下拉电阻**，接在当前**输入脚与板上 GND** 之间，以降低输入悬空导致的误判；
5. 板载 CP2102 的 USB Type-C 串口（推荐用于打印检测结果）。

> 如果只想初筛，可以先用“1 kΩ 串联电阻 + 单根跳线”运行，**但没有明确弱下拉/外部下拉时，断开的输入可能悬空并误判为 PASS**。对疑似故障脚必须加已验证的输入偏置后复测。部分 PDS 版本/IO BANK 支持弱上下拉属性，能否使用应以器件手册和 PDS Pin Planner 实测为准，不要假定工具默认已开启。

### 3.2 单对接线示例：J8-3 与 J8-4

```text
盘古 50K 标准版 J8 正面接触端（示意，非外观方位图）

J8 Pin 3 (EX_IO_11N)  ─── [1 kΩ] ───  J8 Pin 4 (EX_IO_11P)
                                            |
                                         [10 kΩ]  （推荐）
                                            |
                                         J8 GND

第一次：Pin 3 输出，Pin 4 输入；10 kΩ 接在 Pin 4 到 GND。
第二次：Pin 4 输出，Pin 3 输入；将 10 kΩ 改接至 Pin 3 到 GND。
```

**为什么一定在 J8 接触端跳线？** 若把跳线焊在 FPGA 附近、PCB 上游的测试点或 J8 的焊盘上，可能绕开了正要检查的插座焊点，测到的 PASS 就不能证明插座连接可靠。

### 3.3 接线时必须遵守

- **关电后先接线，核对脚号再上电**；不要在通电过程中乱插线或使探针扫过多脚。
- 仅在 J8 **3～36** 之间连接测试线。Pin 2 是 **5V**，禁止连接到 GPIO。
- 默认采用已核实的 **3.3V 单端 IO 标准**；务必核对管脚所属 BANK 的实际 VCCIO，禁止猜测或使用 5V 驱动。
- 任意时刻，每一对最多只能有**一个配置为输出的 IO**；另一脚必须为高阻输入。切换方向时先让双方为高阻，再启用新的输出。
- 整个 J8 不连接其他工作模块（例如摄像头、传感器）；先排除外部驱动冲突。
- 1 kΩ 电阻主要用于减小误连接或短时冲突电流，并**不能保证任意错误接线都安全**。
- 建议通过适配器接触插座端，而不是用过粗或过紧的探针撑坏触点。

## 4. 测试总体结构

```text
                  ┌───────────────────────────┐
50 MHz(P20) ─────>│ test_ctrl（主状态机）      │
                  │ 测试对选择：01～17         │
                  │ 方向选择：A→B / B→A        │
                  │ 测试序列：0/1/交替/PRBS     │
                  │ 采样、比较、计数、超时       │
                  └─────────────┬─────────────┘
                                │
                  ┌─────────────▼─────────────┐
                  │ gpio_pair_mux（17 对 IO）   │
                  │ 仅选中的一对参与测试        │
                  │ 发送方输出，接收方高阻输入  │
                  └─────────────┬─────────────┘
                                │
                       J8 接触端外部环回
                                │
                  ┌─────────────▼─────────────┐
                  │ error_counter / report    │
                  │ PASS / FAIL / INTERMITTENT│
                  └─────────────┬─────────────┘
                                │
                         UART TX (R9)
                                │
                   板载 CP2102 → Windows 串口
```

**测试状态机建议：**

1. `IDLE`：全部 34 路配置为高阻输入，等待开始；
2. `SELECT_PAIR`：接收用户选择的测试对（例如 `03`），检查未选中 IO 全部高阻；
3. `SETTLE`：选定输出方向、放置输入下拉，等待信号稳定；
4. `PATTERN_SEND`：输出 0、1、交替、伪随机（PRBS）逻辑序列；
5. `SAMPLE_COMPARE`：输入至少经两级触发器同步后采样，并与发送值比较；
6. `COUNT_RESULT`：累积样本量、错误数，区分单方向异常和双方向异常；
7. `TRISTATE_SWITCH`：双方先高阻，再交换输入/输出方向；
8. `UART_REPORT`：发送测试对、两个物理脚号、每个方向的 PASS/FAIL 和错误数量；
9. `NEXT/IDLE`：等待用户重新移动跳线或者执行下一对。

**同步和稳定时间**：发送某一测试位后先等待至少 100 μs，再进行输入采样（作为低速首版建议值）；之后可以按需要加长稳定时间。不要在驱动翻转同一个 FPGA 周期直接比较异步输入，否则容易把传播延迟或亚稳态误算成错误。

## 5. PDS 工程建立与 IO 配置

### 5.1 工程建议目录

```text
pangu50k_j8_gpio_diag/
├─ README.md                    # 接线和测试说明
├─ rtl/
│  ├─ gpio_diag_top.v           # Top：时钟、GPIO、串口接口
│  ├─ gpio_pair_mux.v           # 双向高阻驱动与输入采集
│  ├─ gpio_test_ctrl.v          # 17 对选择、方向及测试序列
│  ├─ error_counter.v           # 采样数/错样数/结果锁存
│  ├─ uart_tx.v                 # UART 8N1 发送模块
│  └─ uart_report.v             # 检测信息格式化
└─ constraints/
   └─ j8_gpio_mes50hp.fdc       # 由 PDS 实际版本生成/校验
```

### 5.2 创建工程

1. 在 PDS 中新建 RTL 工程，目标器件选择 **PGL50H-6IFBG484**（速度等级、封装与实物丝印一致）。
2. 将上面的模块添加到工程，以 `gpio_diag_top` 作为顶层。
3. 使用 Pin Planner / 官方 `.fdc` 例程给 **34 路 J8 GPIO** 分配管脚：第 2.1 节表格为**唯一映射清单**。
4. 将 `clk_50m` 约束到 `P20`，`uart_tx` 约束到 `R9`；如需上位机控制，`uart_rx` 约束到 `R8`。
5. 根据所用 IO BANK 的 VCCIO 选择 **LVCMOS33（若实际支持并确为 3.3V）**，确认不启用差分输入模式。输出驱动强度先取低档，不启用不必要的高速功能。
6. 配置未选中 GPIO 为高阻输入；测试切换方向时插入全高阻间隔。
7. 运行综合、布局布线、生成比特流，在 Pin Planner/编译报告中**逐项核查物理引脚和 IO 标准**。
8. **先不接跳线**上板：核对串口能启动并提示等待接线；再关电进行第 3 节的接线和实测。

**不提供未经核实的 `.fdc` 语法作为可直接编译的文件。** 不同 PDS 版本的约束写法或属性支持可能有差异，建议在当前安装版本的 Pin Planner 中建立约束并导出，或以厂商提供的同版板卡例程为起点。

### 5.3 RTL 双向引脚控制参考（仅结构示意）

以下是**一对 GPIO** 的核心控制逻辑，说明如何保证收发方向互斥。它不包含完整的测试状态机和 UART；不能把这段代码当作完整下载工程。

```verilog
// dir = 0: A 输出，B 输入
// dir = 1: B 输出，A 输入
// enable = 0: A/B 均为高阻
module gpio_pair_bidi (
    input  wire enable,
    input  wire dir,
    input  wire tx_data,
    inout  wire io_a,
    inout  wire io_b,
    output wire rx_data
);
    assign io_a = (enable && !dir) ? tx_data : 1'bz;
    assign io_b = (enable &&  dir) ? tx_data : 1'bz;
    assign rx_data = dir ? io_a : io_b;
endmodule
```

顶层可以例化 17 个这样的 IO 单元；未选中的 `enable` 必须为 0。`rx_data` 必须在后续同步、延时稳定之后再做比较。请用 PDS 综合/IO 报告验证内部三态是否已正确映射到**顶层物理引脚**；如有异常，应改用所安装 PDS/器件系列支持的双向 IO 原语。

## 6. 测试模式与工作参数

| 模式 | 内容 | 目的 |
|---|---|---|
| `SMOKE` | 每方向约 100 次、交替 0/1 | 首次确认约束/跳线正确 |
| `NORMAL` | 每方向 **10,000 次**，包含高、低、交替与 PRBS | 常规筛查导通、错位、间歇性故障 |
| `STRESS` | 每方向 **100,000 次**，分时段统计 | 放大低概率接触不良，手动轻触接口观察 |
| `CROSS` | 疑似失效脚与已知正常参考 GPIO 配对 | 进一步缩小故障归属 |

初始建议：单次码元持续约 **1 ms**，在稳定后取 1 次判定值；`NORMAL` 每方向 10,000 次约需 10 秒，不包括等待接线、方向切换和打印时间。测试速率可调，**先从低速开始**。

**测试样本应该包含充分的 0、1 和翻转次数**，不能只发固定高电平。连续全 0 时，断线并被下拉的输入也会显示正确。PRBS 可用最大长度 LFSR 实现，注意固定非零种子和确定性比较时序。

### 6.1 结果判定规则（建议）

- `PASS`：本轮两个方向均无错误且输入偏置、接线验证通过；仅表示**在本次测试条件下未发现异常**。
- `FAIL`：复测后仍出现稳定错误，尤其是样本错误较多或一边完全无法读入。
- `INTERMITTENT`：存在零星错误，或者轻触插座/导线时错误显著增多。
- `INVALID`：未接线、参考脚未确认、输入未设置可靠偏置、串口/约束异常等，**不能用来判断焊点**。

**错误数 1 也不能直接定性虚焊**；需要排除同步时序、连线、接触不良的杜邦头或噪声等因素，再重复确认。

## 7. 如何从“某一对失败”定位到具体 IO

**第一轮（批量筛查）：** 对第 2.1 节中的 17 对，逐对进行 A→B、B→A 检测。记录每一对、每一方向的错误数。每次移动跳线前先将所有 IO 关闭输出，最好关电操作。

**第二轮（排除测试线/方向因素）：** 对失败那一对换一条跳线、重新插牢、重新测试；确保 10 kΩ 下拉跟随接收方切换。观察错误是否能稳定复现。

**第三轮（交叉测试）：** 选择一个已通过测试、并且经实测确认可靠的参考 IO `R`，分别连接疑似故障对中的两只脚，例如原对为 J8-9/10，则另外测试 `R↔J8-9` 和 `R↔J8-10`（两方向各测一次）。

| 交叉复测结果 | 解释 |
|---|---|
| `R↔J8-9` 失败，而 `R↔J8-10` 正常 | **J8-9 路径更可疑**，但仍需排查换线接触和 FPGA 本身 |
| `R↔J8-9` 正常，而 `R↔J8-10` 失败 | **J8-10 路径更可疑** |
| 两个都正常，但原 9↔10 失败 | 优先复核原来的跳线、接线方向、同时驱动冲突及物理相邻触点问题 |
| 两个都失败 | 优先怀疑参考 IO/参考线或共性约束错误，不能贸然判定两脚同时虚焊 |

**第四轮（轻度受力复测）：** 保持合适的测试转接件，轻微改变插座受力方向或轻触连接器附近；如果错误率随受力反复明显变化，应将对应触点列为重点检查对象。不要暴力弯折 PCB 或在带电情况下敲击焊点。

> 最终诊断要区分：J8 焊点虚焊、插座金属触点损坏、杜邦头接触不良、PCB 走线断裂、核心板/底板连接器异常、FPGA IO 损伤、PDS 管脚/IO 标准配置错误。**GPIO 环回只能帮助定位路径异常，并不能单凭软件“验明焊点虚焊”。**

## 8. Windows 串口报告格式

建议借助标准版自带的 **CP2102 USB-UART**。在 Windows 设备管理器找到对应 COM 口；串口助手设置为示例值 **115200 baud、8 数据位、无校验、1 停止位（8N1）**。UART RTL 分频必须匹配 50 MHz 时钟和该波特率。

示例日志**仅为建议输出格式，不代表已在实板运行**：

```text
PANGU50K MES50HP - J8 GPIO DIAGNOSTIC
FPGA=PGL50H-6IFBG484  J8_GPIO=34  PAIRS=17
MODE=NORMAL  SAMPLES_PER_DIRECTION=10000

PAIR=01  J8=03/04  AB13/Y13
  03->04: PASS  errors=0/10000
  04->03: PASS  errors=0/10000

PAIR=04  J8=09/10  AB10/AA10
  09->10: FAIL  errors=387/10000
  10->09: FAIL  errors=416/10000
  NEXT_ACTION: TEST WITH KNOWN-GOOD REFERENCE

PAIR=09  J8=19/20  U10/T10
  19->20: INTERMITTENT  errors=2/10000
  20->19: PASS          errors=0/10000
  NEXT_ACTION: RETEST HARNESS AND CONTACT

SUMMARY: PASS_PAIRS=15  SUSPECT_PAIRS=2
NOTE: A failed PAIR does not by itself identify one bad solder joint.
```

可选：通过 UART RX 设定命令，例如 `PAIR 04`、`RUN NORMAL`、`RUN STRESS`、`REPORT`；第一版不必实现复杂的上位机软件，普通串口助手足够。

## 9. 推荐的实际工作流（按这个顺序执行）

1. **确定板号**：实物为 MES50HP 标准版，确认 J8 物理 Pin1 位置，并用第 2.1 节表格核对管脚。
2. **建立 PDS 测试工程**：先实现 1 对 GPIO 的双向三态和 UART 报告。
3. **无跳线启动检查**：确保无输出冲突、串口/时钟正常；没接线时应显示 `NO LOOPBACK/INVALID`，不能被视为 PASS。
4. **首对验证**：关电连接 J8 3↔4（1 kΩ 串联）、接收端配置合适下拉。运行 `SMOKE`，然后交换方向。
5. **17 对全扫**：依次测试 3↔4、5↔6……35↔36，分别记录两方向数据。每次移线都先禁用输出/关电。
6. **筛出异常**：仅对出现错误的 pair 执行 `STRESS`，更换跳线并重复。
7. **单脚定位**：异常 pair 的两个 GPIO 分别与可靠参考脚跨对测试，比较结果。
8. **验证间歇问题**：对疑似虚焊脚保持低速测试，轻微改变插座受力并记录错误计数变化。
9. **维修确认**：断电后检查和修复可疑焊点；复测所有 17 对，并存档维修前后串口日志。

## 10. 验收标准与能力边界

- 对 **34 路 IO / 17 对连接路径** 完成双向测试。
- 每个方向 `NORMAL` 模式达到约 10,000 个有效样本；全部零错误才能记为本次 `PASS`。
- 所有异常对都有复测、换线、交叉定位记录；不要把一对的 FAIL 直接写成某一只脚虚焊。
- 完成测试后复核 PDS 约束、串口日志和实际插座脚号一致。
- 低速 PASS 不保证高速信号质量、焊点长期可靠性，也不能完全排除相邻脚之间的微弱漏电、短路或环境应力下的间歇故障。
- 对于确有虚焊嫌疑的连接器，建议最终结合断电导通检查、显微镜检查与专业焊接返修进行确认。
