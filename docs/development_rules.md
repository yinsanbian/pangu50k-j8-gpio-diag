# 本工程的开发与验收规范

适用工程：MES50HP 标准版 J8 GPIO 双向环回检测；硬件 FPGA 为 PGL50H-6IFBG484。PDS 2023.2-SP3 的目标参数为 `Logos / PGL50H / -6 / FBG484`，工业温度等级 I 不进入 PDS 的器件字段。

本文件将项目采用的 RTL、引脚、复位、同步器、时序约束与验证要求整理在一处，便于离开开发电脑后继续使用。图像 AXI4-Stream、像素位宽、行缓存、视频 PLL 及项目排期不属于本 GPIO 测试工程。

## RTL

- 每模块登记功能、时序契约与 LATENCY；状态机类注明延迟取决于配置和握手。
- 所有逻辑使用板载 50 MHz，UART 分频和 GPIO 稳定等待使用时钟使能，不生成门控时钟。
- 时序块使用非阻塞赋值，组合块有完整默认赋值和 default 分支；禁止锁存器、多驱动、组合环路、隐式网络。
- 使用确定的异步低有效复位。KEY1 K18 先异步置位内部复位，再同步释放。RTL 禁止 initial、#delay、实数和仿真系统任务。
- GPIO 和 UART 输入至少两级同步；异步时序例外只到第一级寄存器，后级按 50 MHz 正常检查。
- 三态仅在顶层物理 IO，实现全局至多一个驱动；IDLE、方向间隔、取消和报告均关输出。
- 接收输入经过稳定间隔再采样，比较发送的当前码元；计数必须覆盖最后一个有效样本。
- NORMAL/STRESS 模式按硬件默认 1 ms 码元和至少 100 us 稳定间隔运行。仿真缩短等待参数不能改写硬件默认值。

## 约束与工程

- 引脚唯一依据是 MES50HP 原厂手册的 J8 表 3-12、时钟表 2-3、UART 表 3-5、KEY1 表 3-8；不借用其他型号。
- 34 路 GPIO 映射为 j8_gpio[i] ↔ J8 物理 i+3；总顶层 IO 为 38 路：GPIO 34 路、时钟、复位、UART RX/TX。
- J8 使用单端 LVCMOS33、3.3V、4 mA、SLOW；N/P 网络名不启用差分模式。内部拉阻关闭，输入偏置依赖实物已验证的外部电阻。
- FDC 使用当前 PDS 原生 define_attribute 格式；生成 PCF 必须与 38 路清单逐项一致，IO 映射应包含 34 个双向端口。
- GUI 不得同时打开并修改本工程；工程写操作先备份。RTL、约束、脚本和验收摘要可以归档；大型阶段生成物单独存放。
- 创建、综合、映射、布局布线、时序与比特流均已使用 MCP / PDS 验证。公开文档保留摘要；本机许可证信息和原始工具日志不随仓库提交。

## 验收与能力边界

- ModelSim 自检覆盖 17 对双方向、CROSS 端点、三态隔离、方向高阻间隔、断线、稳定错误、间歇错误、非法命令、超时和取消；日志与波形保留。
- PDS 阶段返回成功还须核对日志错误、报告资源、时序和新生成的位流，不依靠退出码单独判断。
- GTP_GRS 原语只有 GRS_N 输入，不能当成上电复位输出使用。当前工程必须在下载或上电后按 KEY1 复位，再操作串口。
- 软件结果描述环回路径及本轮样本。失败不能直接指定某个焊点；未接线、偏置/参考未经确认等条件必须标 INVALID。
- 本次工程开发和离线验证不执行板卡下载，不替代实板接线、BANK 电源核查和焊点导通检查。
