# GPIO 环回仿真计划

仿真只验证 RTL、异步输入同步、引脚方向控制和串口行为，不作为板卡焊点导通或实际下载结果。

`tb_gpio_core.sv` 通过 `gpio_pair_mux` 的 34 路真实 `inout` 网络形成测试闭环。外部连接模型读取发送脚实际解析电平，在 2 ns 传播延迟后返回至接收脚，每脚使用弱下拉。断路移除外部回路；固定高、单向反相与间歇故障仅注入接收端。未把内部 `tx_data` 直接连接至控制器输入。

默认生产样本量完整保留：SMOKE 100 / NORMAL 10,000 / STRESS 100,000（每方向）。仅把码元、采样等待、全高阻间隔分别缩短为 16 / 8 / 8 时钟，以便检查全部计数和边界。独立参考模型生成交替、连续低、连续高与 PRBS16；PRBS seed 为 `0x1ACE`，反馈位置为 15、13、12、10。

| 检查范围 | 通过条件 |
|---|---|
| 17 个标准相邻测试对 | 各对双向 100 个样本，零错误且 PASS |
| CROSS 任意脚 | 首末脚、跨对、反向选择均双向通过 |
| 资格与配置检查 | 未确认、非法脚、同脚、非法模式不启用输出，结果 INVALID |
| 输出互斥 | 每个时钟最多一个输出；只驱动已选择脚 |
| 方向切换 | 完整 8 周期全高阻间隔后才允许另一个脚输出 |
| 无环回与固定高 | 检查错误计数及只观察一种电平的 INVALID 分类 |
| 单方向稳定故障 | 故障方向 FAIL，另一个方向 PASS |
| 间歇故障 | 恰好 1/100 错误，结果 INTERMITTENT |
| 判定阈值边界 | 10/100 为 INTERMITTENT，11/100 为 FAIL |
| 配置锁存 | 运行中改变 pin/mode/qualified 和重复 START 不改变当前测试 |
| NORMAL 四段序列 | 每方向 10,000 个样本逐位匹配独立参考 |
| STRESS 时段统计 | 每方向 100,000 个样本；5 次 AB 错误分布在不同 10k 时段，MAX10K=2 |
| 中止 | 初次稳定、AB 运行、全高阻切换、BA 运行均停止并释放输出，结果 INVALID |
| 重启与复位 | 中止后重启通过；异步复位在输出期间立即释放引脚 |

`block_errors_ab/ba` 按每 10,000 个样本依次分块，取所有块的最大错数（含不足 10,000 个样本的尾块），不是滑动窗口或四类码型的错误计数。

通过 `scripts/pango_call.mjs` 的 JSON-RPC/stdio MCP 客户端调用 `fpga_msim_sim`，由 ModelSim 编译和执行。以自检台的 `TB_PASS` 标记、所有断言通过及 MCP `ok=true` 共同判断通过。串口顶层集成台另测命令解析、确认流程、完整 ASCII 报告、STOP 与错误帧。本仓库保留脱敏摘要；原始工具记录仅保留在本机。

`production_test/tb_gpio_production.sv` 不覆盖任何顶层参数：50 MHz、115200 baud（分频 434）、50,000 周期码元、5,000 周期稳定等待与 5,000 周期全高阻间隔。实际串口驱动发送 PAIR 01、ARM、RUN SMOKE，完整比对 115200 baud ASCII 报告，检查真实两个方向各 100 个样本，记录输出翻转到采样的物理时间及换向间隔。只转储 12 条变化较慢的信号，不转储时钟或周期计数器，生成小型 `reports/gpio_production.vcd`。

复现全部测试：`./sim/run_sim.ps1 -Test all`。也可选 `core`、`uart`、`production`。脚本按所在目录生成绝对源路径，通过 pango-mcp 顺序执行仿真并将 transcript 和结果归档至 `reports/`；生产台使用独立 ModelSim 工作目录。
